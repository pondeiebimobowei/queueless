# QueueLess — Design System

Version: 1.0

## Principles
- Mobile-first
- Clarity over decoration
- Fast to scan
- Consistent spacing
- Accessible by default

## Brand Attributes
- Calm
- Reliable
- Efficient
- Modern
- Trustworthy

## Color Tokens
### Primary
- Primary 500: #2563EB
- Primary 600: #1D4ED8

### Success
- #16A34A

### Warning
- #F59E0B

### Error
- #DC2626

### Neutral
- Gray 50–900 (Tailwind palette)

## Typography
- Font: Inter
- Display: 32/40 Bold
- H1: 28/36 Bold
- H2: 24/32 Semibold
- H3: 20/28 Semibold
- Body: 16/24 Regular
- Caption: 14/20 Regular
- Label: 12/16 Medium

## Spacing
4, 8, 12, 16, 24, 32, 48, 64 px

## Radius
- Small: 8
- Medium: 12
- Large: 16
- XL: 24

## Elevation
Use subtle shadows only for floating surfaces.

## Icons
Material Symbols Rounded.

## Grid
8pt spacing system.

## Components
- Button (Primary, Secondary, Ghost, Destructive)
- Text Field
- Search Field
- Card
- List Item
- Queue Card
- Staff Card
- Avatar
- Badge
- Chip
- Snackbar
- Bottom Sheet
- Dialog
- Tabs
- Bottom Navigation
- Top App Bar
- Progress Indicator
- Empty State
- Error State

## States
Default, Hover, Focus, Pressed, Disabled, Loading.

## Motion
- 200–300ms
- Ease-out
- Purposeful only

## Accessibility
- WCAG AA
- Touch targets >=44x44
- Dynamic text
- Screen reader labels

## Responsive
Primary target:
- Mobile phones
Secondary:
- Tablets

## Design Rules
- One primary CTA per screen.
- Avoid nested dialogs.
- Keep forms short.
- Show queue status prominently.
- Prefer plain language over jargon.
